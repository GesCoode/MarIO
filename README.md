MAR[IO] && L[UI]GI
Pull the codebase and then from that folder do:
cabal run

Click Single Player or Two Players, then click a level.
There are three levels:
- 1.1 Mario clone (horizontal level)
- Vertical level (Procedurally generated)
- Boss fight

There is also the campaign that chains these three levels together.
For debugging there is also a sandbox level.

CONTROLS
Mario
Left | `A` 
Right | `D`
Jump | `W`

Luigi
Left | `←`
Right | `→`
Jump | `W`

`p` pause, `r` restart, `c` wireframe/debug view, `Esc` back to the menu.

Warning: Do not change the screen size. It was not meant to be played at higher resolutions.
